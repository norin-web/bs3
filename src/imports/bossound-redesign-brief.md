# ТЗ: редизайн сайта Bossound в стиле Sonos

## 1. Контекст задачи

Есть сайт bossound.store — интернет-магазин аудиотехники (наушники, портативные и домашние колонки), собранный по стандартному e-commerce паттерну: тёмная тема с цветными градиентами, карточки товаров со скруглениями и тенями, плотный header, много визуального шума на экран.

Референс стиля — sonos.com (раздел /en-us/home). Нужно перенести визуальный язык Sonos (минимализм, крупная типографика, чередование чёрных/белых секций, lifestyle-фотография, отсутствие декора) на структуру и контент Bossound, сохранив бренд и товарную линейку.

Задача агента: пересобрать визуальную систему сайта (не логику/бэкенд) — лейаут, типографику, цвет, компоненты, фотостиль — согласно правилам ниже.

## 2. Design tokens

### Цвет
```
--black:      #0a0a0a   /* основной тёмный фон */
--white:      #ffffff   /* основной светлый фон */
--off-white:  #f5f5f3   /* альтернативный светлый фон (футер, статичные секции) */
--gray-mid:   #8a8a8a   /* вторичный текст */
--gray-line:  #e4e4e0   /* тонкие разделители, границы карточек */
```
Правило: цвет в интерфейсе — только чёрный/белый/серый. Любой другой цвет допускается исключительно как часть реальной фотографии товара (естественный свет, без цветокоррекции в неон/градиент). Никаких градиентных заливок фона, никаких acid-цветов.

### Типографика
- Display-шрифт (заголовки): геометричный гротеск с плотным трекингом — Archivo (700-800) или аналог (Neue Haas Grotesk, Helvetica Now Display).
- Body-шрифт: Inter, вес 400-600.
- Заголовки — **uppercase**, `letter-spacing: -0.02em`, `line-height: 0.95`.
- Масштаб:
  | Роль | Размер (desktop) | Размер (mobile) |
  |---|---|---|
  | H1 (hero) | clamp(44px, 7vw, 96px) | 36-44px |
  | H2 (секции) | clamp(32px, 4.5vw, 56px) | 28-32px |
  | H3 (карточки) | 20-24px | 18-20px |
  | Body | 16-17px | 15-16px |
  | Caption/label | 12-13px, uppercase, letter-spacing 0.04-0.12em | — |
- Цвет вторичного текста — `--gray-mid`, не чёрный.
- Максимальная длина параграфа под заголовком — 1-2 предложения, ≤ 480px по ширине.

### Отступы / ритм
```
--gap-xl: 160px   /* между крупными секциями на desktop */
--gap-lg: 96px
--gap-md: 48px
```
На мобильных — сокращать вдвое, но не убирать полностью: воздух между секциями — часть стиля.

### Кнопки
- Один паттерн на весь сайт: прямоугольная (`border-radius: 0` или максимум 2-4px), без теней и градиентов.
- Инверсия цвета: светлая кнопка на тёмной секции (белый фон/чёрный текст), тёмная — на светлой.
- Hover: заливка становится прозрачной, остаётся только обводка того же цвета, что была заливка.
- Паддинг: `15px 28px`. Текст: 13px, uppercase, `letter-spacing: 0.04em`, шрифт с весом 600.
- Подписи — короткие, глагольные: "Shop now", "Explore", "Learn more". Не больше одной кнопки-акцента на экран.

### Карточки (товары, сценарии использования)
- Без теней, без скруглений (или максимум 2px).
- Разделение карточек в сетке — тонкой линией 1px (`--gray-line` на светлом фоне, `#1c1c1c` на тёмном), а не отступом с тенью.
- Фото товара — вверху карточки, aspect-ratio 4:3 или 1:1, object-fit cover.
- Цена — маленьким текстом (14px) под названием, без зачёркнутых "было/стало" и ярких скидочных бейджей.
- Никаких бейджей "New" / "Hit" / рейтинга звёздами на карточке в каталожной сетке — это шум, у Sonos его нет.

## 3. Структура страницы (порядок секций)

Пересобрать главную как сторителлинг, а не каталог:

1. **Header** — фиксированный, прозрачный поверх hero, становится сплошным при скролле.
2. **Hero** — полноэкранный (100vh) блок с фото/видео товара в реальной обстановке, один слоган, одна кнопка CTA.
3. **Emotional statement** — короткий блок "почему наш звук лучше" с 2-3 короткими фактами/цифрами (не иконки-фичи, а типографика).
4. **Play your way** — 3 карточки по сценариям использования ("дома", "в дороге", "для видео/ТВ"), каждая ведёт в соответствующую категорию каталога.
5. **Как это работает / приложение** — блок с UI-скриншотами приложения (mockup телефона), объясняющий настройку в 2-3 шага.
6. **Каталог / товарная сетка** — плоские карточки, минимальная сетка 3-4 колонки.
7. **Соцдоказательство** — цитата эксперта/отзыв с фото, крупным шрифтом.
8. **Подписка + футер** — форма email в одну строку, затем многоколоночный футер (Помощь / О компании / Категории / Соцсети), мелкий текст.

## 4. Компонент: Header

- Layout: логотип слева, 3-4 пункта меню по центру/справа, иконки поиска и корзины — тонкие линии без заливки, справа.
- На hero — `mix-blend-mode: difference` или белый текст поверх тёмного фото, чтобы не требовался отдельный тёмный подложка-бар.
- При скролле вниз — фон header становится белым (или чёрным на тёмных секциях), текст — контрастным.
- Убрать: бейджи акций, лишние иконки (аккаунт, избранное) из основной строки — вынести в меню/дропдаун при необходимости.

## 5. Компонент: Hero

- Высота: `100vh`, `min-height: 640px`.
- Фон: фото или видео (автоплей, без звука, loop) — товар в реальной обстановке (на улице, в интерьере, в движении), НЕ студийное фото на однотонном фоне.
- Оверлей: линейный градиент затемнения снизу вверх (`rgba(0,0,0,0.65)` внизу → `rgba(0,0,0,0.05)` в середине) — только для читаемости текста, не декоративный цветной градиент.
- Текст: прижат к нижнему краю блока (не по центру экрана), выровнен по левому краю.
- Контент: eyebrow-лейбл (12px, uppercase) → H1 (короткий слоган, 3-6 слов) → 1 строка описания (≤ 420px) → 1 кнопка CTA.

## 6. Фотостиль

- Приоритет — lifestyle-съёмка: человек использует товар в реальной среде, естественный свет, минимальная цветокоррекция.
- Студийные фото на нейтральном фоне — только в карточках каталога, не в hero/промо-блоках.
- Никаких неоновых подсветок, дым-эффектов, цветных студийных фонов (фиолетовый/синий неон, которые сейчас используются на bossound.store) — это главное, что нужно убрать в первую очередь.

## 7. Анимация / интерактив

- Минимально: fade-in + небольшой translateY при появлении блока в вьюпорте (scroll-reveal), без разлётов/поворотов.
- Hover на кнопках/карточках — только смена цвета/обводки, без scale и теней.
- Уважать `prefers-reduced-motion` — отключать анимации при этом флаге.

## 8. Что убрать с текущего сайта (bossound.store)

- Цветные градиентные фоны за текстом (зелёные/неоновые подложки в hero).
- Тени и скругления у карточек товаров.
- Бейджи рейтинга/скидок на карточках каталога.
- Плотный header с большим количеством иконок в одной строке.
- Иконочные панели фич (доставка/поддержка) как отдельный декоративный блок — заменить текстовым блоком или перенести в футер.
- Множественные разностильные CTA-кнопки на одном экране.

## 9. Референсы

- Стиль: https://www.sonos.com/en-us/home
- Текущий сайт (что переделываем): https://bossound.store/
- Рабочий пример hero-секции в новом стиле (уже собран): bossound-sonos-style-mockup.html (прилагается отдельно)

## 10. Критерий готовности

- На каждом экране — не больше одного акцентного CTA.
- Ни одного градиентного/неонового фона в интерфейсе.
- Все карточки — единый паттерн (без смешения скруглений/теней между блоками).
- Header не длиннее 6 элементов в строке.
- Контраст текста ≥ WCAG AA на всех секциях (в т.ч. поверх фото в hero).
