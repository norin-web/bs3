# Technical Specification
# Project: BEN OLSEN・Sound Connect
# Type: Promotional Landing Page for an App
# Platform: Web
# Primary Goal: Drive users to the App Store and encourage app installation

---

## 1. General Project Information

### 1.1. Project Name
BEN OLSEN・Sound Connect

### 1.2. Website Type
A promotional landing page for a mobile app that controls connected devices.

### 1.3. Main Business Goal
The website must present the app in a premium way and lead users to the main target action:
- go to the App Store
- install the app
- understand the app’s value
- trust the brand
- easily find support, contact details, feedback options, and legal pages

### 1.4. Main Reference
Bang & Olufsen website as the stylistic benchmark:
- premium minimalism
- large visual hero sections
- calm and expensive color palette
- generous whitespace
- large typography
- concise copy
- product-first composition
- high attention to spacing, layout, and rhythm
- smooth and subtle animations
- luxury-tech brand feeling

### 1.5. Important Note
The website should feel максимально close in mood, visual language, patterns, color usage, and UX direction to Bang & Olufsen, but it must not be a literal copy. The goal is to keep the recognizable premium aesthetic while adapting it to the BEN OLSEN・Sound Connect brand.

## 7. Style and Design System

### 7.1. Stylistic Foundation
The visual language should be based on Bang & Olufsen-inspired principles:
- large hero visuals
- generous whitespace
- restrained neutral-luxury colors
- contrast between light and dark sections
- product-first layouts
- wide modular sections
- minimal cards
- short and elegant copy
- subtle motion design

### 7.2. Color Palette
The palette should be inspired by a B&O-like approach:
- soft off-white
- warm ivory / sand
- matte black / charcoal
- muted grey
- warm metallic beige
- subtle bronze / champagne accents
- optional deep olive / muted green / terracotta accents

### 7.3. Recommended Base Palette
- Background Light: #F5F1EA
- Background Warm: #EAE3D8
- Background Dark: #111111
- Surface Grey: #D9D2C7
- Text Primary Dark: #121212
- Text Light: #F7F5F1
- Accent Warm Metal: #B59A7A
- Accent Muted Olive: #78806E

### 7.4. Color Usage Principles
- 70% neutral and calm base
- 20% dark contrast sections
- 10% subtle accents
- avoid bright, acidic, overly digital colors
- avoid cheap-looking gradients
- gradients are allowed only if extremely soft and almost invisible

### 7.5. Typography
Typography should feel large, premium, and confident.

Recommended direction:
- headlines: modern serif or premium grotesk
- body text: clean grotesk / neo-grotesk
- combination of elegant editorial feeling and high-end tech minimalism

### 7.6. Typography Rules
- large headlines
- short and meaningful statements
- generous line spacing
- no overloaded paragraphs
- copy must feel like luxury product communication
- avoid noisy marketing language and cheap promises

### 7.7. Grid
- desktop: 12-column grid
- tablet: 8-column grid
- mobile: 4-column grid

### 7.8. Spacing
- large vertical rhythm
- wide side margins
- generous whitespace
- visually expensive spacing between content blocks

### 7.9. Border Radius
- moderate
- not too soft
- not bubble-like
- premium, strict, and clean

### 7.10. Shadows
- very soft
- barely noticeable
- no cheap UI effects
